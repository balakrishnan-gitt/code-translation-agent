Turn a JavaScript file into Python without renaming anything.

The agent reads a local .js file, rewrites its logic in Python, and keeps every variable and function name exactly as you wrote it.

View on GitHub Run it locally

input.js

const taxRate = 0.18;

function calcTotal(cartItems) {
  let totalPrice = 0;
  for (const item of cartItems) {
    totalPrice += item.price * item.qty;
  }
  return totalPrice * (1 + taxRate);
}

output.py

taxRate = 0.18

def calcTotal(cartItems):
    totalPrice = 0
    for item in cartItems:
        totalPrice += item["price"] * item["qty"]
    return totalPrice * (1 + taxRate)

Hover or tap a name to see it matched on both sides. Python style would use total_price; this agent keeps totalPrice.

How the agent works

The agent runs a short loop and only stops when the Python file passes its checks.

  1. Read the fileA read_file tool loads the JavaScript from the path you pass in.
  2. List the namesIt extracts every variable, function and parameter name, so there is a fixed list to protect.
  3. TranslateA rule-based translator rewrites each construct (functions, loops, if/else, objects, classes) as Python, leaving every name untouched.
  4. VerifyPython's ast module parses the output, then the agent compares its names against the list from step 2.
  5. Repair or saveOn a syntax error, the agent uses the error line to fix or flag that line, then checks again. On success, it writes output.py.

The naming rule

Names stay the same. Syntax changes where Python requires it.

userNameuserNamecamelCase is kept, not converted to snake_case

A name that is a Python keyword, such as from or lambdafrom_, lambda_The only allowed rename, reported in the log

Needs Python 3.8 or newer. No API key and no extra packages.

What it handles

  • Functions, loops, conditionals
  • Arrays and objects, as lists and dicts
  • Classes, template strings, ternaries, try/catch

Known limits

  • Async code and the DOM have no direct Python match
  • Lines it cannot translate (such as switch) are marked TODO
  • Output is checked for syntax and names, not for behavior
  • Review the result before you rely on it
