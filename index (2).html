      How the agent works
      
      
      A loop, not a one-shot script: it checks its own work and repairs it.
      
      
      
      
        
        
      1. Extract names. Every variable, function, class and parameter is listed so there is a fixed set to protect.
        2. 
        
      2. Translate. Strings and comments are hidden first, so rules never touch them. Each construct is then rewritten as Python.
        3. 
        
      3. Verify. Python's ast parses the result, then every JS name must still exist in it.
        4. 
        
      4. Repair. A line that cannot be translated becomes pass with a TODO, so the file always runs.
        5.

      Testing and limits
      
      
      What was checked, and what the agent does not do.
      
      
      
        
      Checked
        
          
      • Command-line and browser versions give identical output on 5 test files
        • 
          
      • Every output is parsed with Python's ast
        • 
          
      • Each JS name must exist in the Python, or it is reported
        • 
          
      • Names inside strings and comments are ignored
        • 
          
      • Unsupported code gets a TODO instead of breaking the file
        • 
        
      
        
      Not covered
        
          
      • switch, async/await and DOM code
        • 
          
      • Destructuring, such as const {a, b} = obj
        • 
          
      • Behavior: output is checked for syntax and names, not run against tests
        • 
          
      • Next step: a real JS parser and generated test cases
        •
